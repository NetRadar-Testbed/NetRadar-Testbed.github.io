# Citing NetRadar

NetRadar is free to use under the Apache-2.0 licence. If you use this software,
or a testbed built with it, in published work, we ask that you:

1. **Cite our papers** (below), and
2. **State that your testbed was built using the NetRadar open-source
   software**, including the version you used.

## Papers

```bibtex
@INPROCEEDINGS{11205142,
  author={Banik, Anirban and Giridhar, Lalitha and Kattekola, Aaditya Prakash and Pallaprolu, Anurag and Mostofi, Yasamin and Sabharwal, Ashutosh and Madhow, Upamanyu},
  booktitle={2025 IEEE Radar Conference (RadarConf25)},
  title={mmSnap: Bayesian One-Shot Fusion in a Self-Calibrated mmWave Radar Network},
  year={2025},
  pages={1116-1121},
  doi={10.1109/RadarConf2559087.2025.11205142}}

@INPROCEEDINGS{10942741,
  author={Banik, Anirban and Mostofi, Yasamin and Sabharwal, Ashutosh and Madhow, Upamanyu},
  booktitle={2024 58th Asilomar Conference on Signals, Systems, and Computers},
  title={Optimal Self-Calibration for Collaborative Sensing in mmWave Radar Networks},
  year={2024},
  pages={218-222},
  doi={10.1109/IEEECONF60004.2024.10942741}}
```

## Suggested acknowledgement

> The radar testbed used in this work was built with the open-source NetRadar
> software [mmSnap, Asilomar 2024] (https://github.com/NetRadar-Testbed,
> version X).

Use the release tag (e.g. `v1.0.0`) or commit you used for "version X".

## From GitHub

Each repository has a `CITATION.cff` file, so GitHub's **Cite this repository**
button (right-hand sidebar) gives these entries in BibTeX and APA format.
